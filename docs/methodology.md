# Methodology

## Study Design

A single generated ordinal dataset is analyzed using two CFA approaches.

## Population Model

The population model contains one latent factor and five observed indicators.

The population standardized factor loading is 0.70 and factor variance is 1.

## Ordinal Data

Continuous responses are generated and categorized into four ordinal categories using thresholds at the 25th, 50th, and 75th standard-normal quantiles.

## Estimation

The first analysis uses WLSMV directly on the ordinal indicators.

The second analysis uses a CFA model based on a polychoric correlation matrix.

## Fit Indices

CFI and RMSEA are treated as primary fit indices.

TLI, SRMR, chi-square, and p-value are reported as secondary fit information.

## Reproducibility

The analysis uses a fixed random seed.
